### 2. Verilog/SystemVerilog 코드 블록 테스트

비동기 리셋을 포함한 간단한 D 플립플롭(D Flip-Flop) 모듈입니다. 상단 패널에 'Verilog' 제목이 출력되는지와 `module`, `wire`, `reg`, `always` 키워드가 정상적으로 강조되는지 확인합니다.

```verilog
module d_ff (
    input wire clk,
    input wire rst_n,
    input wire d,
    output reg q
);

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            q <= 1'b0;
        end else begin
            q <= d;
        end
    end

endmodule
```
```systemverilog
interface bus_if (input logic clk);
    logic [7:0]  addr;
    logic [31:0] data;
    logic        valid;

    modport master (output addr, data, valid, input clk);
    modport slave  (input addr, data, valid, clk);
endinterface

module data_reg (
    input  logic clk,
    input  logic rst_n,
    input  logic [31:0] d_in,
    output logic [31:0] q_out
);

    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            q_out <= '0;
        else
            q_out <= d_in;
    end

endmodule
```
